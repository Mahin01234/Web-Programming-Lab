1. Document Structure

Every HTML5 document starts with <!DOCTYPE html>. The <html> element wraps everything, containing <head> (metadata) and <body> (visible content). 

<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <title>Page Title</title>
  </head>
  <body>
    Content goes here
  </body>
</html>

6. Semantic HTML

Semantic tags describe the meaning of content, improving accessibility, SEO and maintainability.

  • <header> — Intro / navigation area
  • <nav> — Navigation links
  • <main> — Main unique content
  • <section> — Thematic grouping
  • <article> — Independent, self-contained content
  • <aside> — Side content related to main content
  • <footer> — Footer for a page or section
  • <figure> — Self-contained media with optional caption

8. Block-level vs Inline Elements

Block-level Elements

11. Best Practices & Common Mistakes

Best Practices ✅

  1. Always declare <!DOCTYPE html>
  2. Use lowercase tag names
  3. Quote all attribute values
  4. Provide alt text for every image
  5. Prefer semantic tags over <div>
  6. Close tags and nest properly
  7. Keep structure clean and indented
  8. Validate HTML at validator.w3.org

Common Mistakes ❌

  • Missing DOCTYPE
  • Unclosed tags
  • Wrong nesting (blocks inside <p>)
  • No alt on images
  • Using <b>/<i> instead of <strong>/<em>
  • Inline styles everywhere

Quick Tip

Type the tags yourself instead of copy-pasting — muscle memory comes from writing. Open the page in a browser often (Save → Refresh) and use DevTools (F12) to inspect the DOM.
